# Changelog

## 0.1.0 — 2026-09-25

First packaged project version, following the original session research:

- Deterministic session calibration and conservative per-frame Bayer correction.
- Optional scene-assisted residual refinement, explicitly labeled experimental.
- Verified DNG export with macOS Preview-compatible EXIF placement.
- Reusable delivery evaluation, source/gain integrity checks and matched-run diagnostics.
- MIT licensing, documentation, source/wheel packaging and public CI without private photos.
- A concise, de-identified [provenance journal](docs/journal.md); private research artifacts are excluded from the public source.

Package versioning starts at 0.1.0; no package registry release is implied by this entry. The public repository starts from a sanitized source snapshot. Earlier private milestones are described in the journal; private history and tags are not published.
